<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| affiliate browser → dashboard server component | Authenticated affiliate session; cookie validated by middleware then re-checked by `getAffiliateSessionId()` in the page body before any creative data is read |
| dashboard → Vercel Blob CDN (`*.public.blob.vercel-storage.com`) | Public CDN serving admin-uploaded marketing assets; reached via `<Image>`, `<video src>`, and the `getDownloadUrl` download anchor |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-01 | Spoofing / Elevation of privilege | Affiliate dashboard page (Criativos section) | mitigate | Section renders inside the existing guard: middleware redirects unauthenticated requests, and `getAffiliateSessionId()` + `getAffiliateDashboardData()` redirect to login before the section is reached. No new route or API is introduced; `listCreatives` is called only after the guard. Task 3 verifies the call sits after the redirect checks. |
| T-03-02 | Information Disclosure | Creative blob URLs (public CDN) | accept | Creative blob URLs are public on the Vercel CDN by design — they are on-brand marketing assets meant for distribution by affiliates. No PII, no secrets. Accepted residual, not a blocker. |
| T-03-03 | Cross-site Scripting (XSS) | `row.caption` / `row.title` rendered on cards | mitigate | Caption and title are rendered as plain React text children (`{row.caption}`, `{row.title}`), which React auto-escapes. Task 2 forbids `dangerouslySetInnerHTML` and forbids rendering caption as a `<track>`/subtitle overlay. |
| T-03-04 | Tampering | `getDownloadUrl(row.url)` download anchor | accept | `getDownloadUrl` only appends `?download=1` to an admin-uploaded blob URL; no user-supplied URL is involved and no re-routing occurs. URLs originate from admin-authenticated Phase 2 uploads. Accepted residual. |
| T-03-05 | Information Disclosure | `navigator.clipboard.writeText(caption)` | accept | Caption is admin-authored marketing text (not a secret); clipboard write is user-initiated via an explicit button click. Accepted residual. |
| T-03-SC | Tampering | npm/pip/cargo installs | mitigate | No new packages are installed in this phase (RESEARCH "No new packages are needed"; Package Legitimacy Audit reports none added). No install task exists, so no legitimacy checkpoint is required. |

No `high`-severity threats identified; nothing blocks. The single blocking gate is the human-verify checkpoint for functional/visual confirmation.
