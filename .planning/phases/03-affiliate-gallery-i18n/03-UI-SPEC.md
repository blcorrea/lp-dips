### Responsive Grid

```
grid grid-cols-1 sm:grid-cols-2 md:grid-cols-3 gap-4
```

Breakpoints:
- Default (< 640px): 1 column
- `sm` (≥ 640px): 2 columns
- `md` (≥ 768px): 3 columns

No 4th or 5th column. The `max-w-4xl` container (896px) with a 3-col grid at ≥768px gives comfortable card widths (~280px each) with sufficient room for the inline video player.

Source: CONTEXT D-09; verified against admin grid which uses `sm:grid-cols-2 md:grid-cols-3` as its base.

### Creative Card

Card shell:

```
rounded-2xl bg-white/10 backdrop-blur-sm overflow-hidden flex flex-col
```

#### Media Frame

```
relative aspect-video w-full bg-black/20
```

Aspect ratio: `aspect-video` (16:9) for all cards (IMAGE and VIDEO). Ensures uniform row height in the grid.

**IMAGE card** — `next/image`:

```tsx
<Image
  src={row.url}
  alt={row.title}
  fill
  className="object-cover"
  sizes="(max-width: 640px) 100vw, (max-width: 768px) 50vw, 33vw"
/>
```

**VIDEO card — with thumbnailUrl** (poster available):

```tsx
<video
  src={row.url}
  poster={row.thumbnailUrl}
  controls
  preload="none"
  className="w-full h-full object-cover"
/>
```

**VIDEO card — no thumbnailUrl** (poster absent):

Render a centered icon placeholder. The `<video>` element is mounted but visually hidden (opacity-0) so it activates on click:

```tsx
<div className="flex h-full items-center justify-center">
  <Video className="w-10 h-10 text-white/40" />
</div>
<video
  src={row.url}
  controls
  preload="none"
  className="absolute inset-0 w-full h-full opacity-0 cursor-pointer"
/>
```

Icon: `Video` from `lucide-react`, size `w-10 h-10` (`40px`), color `text-white/40`.

#### Type Badge

Position: absolute, top-left corner.

```
absolute top-2 left-2 inline-flex items-center px-2 py-0.5 rounded-full text-[11px] font-bold tracking-[0.08em] uppercase bg-black/50 text-white
```

Content: localized string — `t('photoLabel')` / `t('videoLabel')`. No icon — text only.

#### Card Body

```
p-4 flex flex-col gap-3 flex-1
```

**Title** (always shown):

```
text-white font-semibold text-sm truncate
```

**Caption text** (only when `row.caption` is non-empty):

```
text-white/60 text-xs line-clamp-3
```

Plain `<p>` element. Never render as `<track>` or subtitle overlay. This is admin-authored social post text (D-05).

**Action row**:

```
mt-auto flex gap-2 flex-wrap
```

#### Download Button (anchor element)

```tsx
<a
  href={getDownloadUrl(row.url)}
  download={row.fileName}
  className="inline-flex items-center rounded-xl bg-brand-orange px-4 py-2 text-xs font-bold text-brand-purple transition-all duration-200 hover:bg-brand-orange/90 active:scale-95"
>
  {t('download')}
</a>
```

Implementation notes:
- Must be an `<a>` element, not a `<button>`, to enable keyboard navigation and right-click "Save link as".
- `href` must use `getDownloadUrl(row.url)` from `@vercel/blob` — never raw `row.url` (cross-origin `download` attribute is ignored by browsers without `Content-Disposition: attachment`).
- `download={row.fileName}` is the suggested filename; the CDN `Content-Disposition` header also carries it.
- Color: `bg-brand-orange` background, `text-brand-purple` label — matches CopyLinkButton's button style exactly.

#### Copy Caption Button (only when `row.caption` is non-empty)

```tsx
<button
  type="button"
  onClick={() => handleCopy(row.id, row.caption!)}
  className="inline-flex items-center rounded-xl border border-white/20 px-4 py-2 text-xs font-bold text-white transition-all duration-200 hover:bg-white/10 active:scale-95"
>
  {copiedId === row.id ? t('copied') : t('copyCaption')}
</button>
```

Visual state:
- Default: glass outline — `border border-white/20 text-white bg-transparent`
- Copied confirmation: same button, text swaps to `t('copied')` — no color change needed (text swap is sufficient feedback)
- Hover: `hover:bg-white/10` — subtle glass fill
- Active: `active:scale-95`

Behavior:
- `navigator.clipboard.writeText(caption)` — async, try/catch, silent on failure (per CopyLinkButton convention)
- `copiedId` state atom: `string | null` — tracks which card is in confirmed state. Reset after 2000ms.
- Only one card can be in "copied" state at a time.

When `row.caption` is null or empty: render neither the caption `<p>` nor this button. Zero visible remnant.

### Empty State

Shown when `creatives.length === 0`. Replaces the grid entirely (matches `noCommissions` pattern).

```tsx
<p className="px-6 py-10 text-center text-white/40 text-sm">
  {t('noCreatives')}
</p>
```

Padding: `px-6 py-10` — matches commission history empty state exactly. No icon, no heading, no CTA — single centered message only.

## Interaction States

### Video Playback

| State | Visual |
|-------|--------|
| Default (paused) | Poster image fills media frame (or icon placeholder if no poster). Native controls bar visible at bottom. |
| Playing | Native browser video controls active. No custom chrome. |
| Hover | No custom hover on video frame — native browser behavior. |

`preload="none"` — no network request until user explicitly clicks play. Combined with `poster`, the grid shows still frames at zero bandwidth cost.

### Download Anchor

| State | Visual |
|-------|--------|
| Default | `bg-brand-orange`, `text-brand-purple` |
| Hover | `hover:bg-brand-orange/90` (slight darken) |
| Active / click | `active:scale-95` (press feedback) |
| Focus | Browser default focus ring — do not suppress |

### Copy Caption Button

| State | Visual |
|-------|--------|
| Default | Glass outline `border-white/20 text-white` |
| Hover | `hover:bg-white/10` |
| Active / click | `active:scale-95` |
| Copied (0–2000ms) | Text label swaps to `t('copied')` — no other visual change |
| Focus | Browser default focus ring — do not suppress |

### Card Hover

No card-level hover effect (no scale, no shadow shift). Individual interactive elements (anchor, button) handle their own hover states. This is consistent with the commission table rows which use `hover:bg-white/5` but cards do not transform.

## Anti-Patterns (executor must avoid)

| Anti-Pattern | Correct Approach |
|---|---|
| `<a href={row.url} download>` without `getDownloadUrl` | Always `href={getDownloadUrl(row.url)}` — cross-origin `download` attribute requires `Content-Disposition: attachment` |
| `fetch → blob → objectURL` for download | Never — buffers 200MB files in browser memory. `getDownloadUrl` streams to disk |
| `autoplay` or `muted autoplay` on `<video>` | `preload="none"` + `controls` only. Autoplay was explicitly rejected (D-02) |
| `<Image>` for the VIDEO media frame | `<video src={row.url}>` for the playable frame. `<Image>` for IMAGE type and poster-only thumbnails in admin only |
| `<track>` or subtitle overlay using `row.caption` | `row.caption` is plain social text — render in `<p>` only (D-05) |
| Importing `listCreatives` in the client component | Server component passes serialized `CreativeRow[]` as prop; client component never imports from `creatives.ts` |
| Admin white-card style (`bg-white`, `border-gray-200`) | Affiliate section uses glassmorphism — `bg-white/10 backdrop-blur-sm` |
