| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-05-04 | Injection (XSS) | Hero `t.rich("h1", ...)` | mitigate | The `<hl>` chunk is rendered by a code-defined React callback returning a `<span>` — next-intl rich text does NOT inject raw HTML from the message; message stays data, markup comes from the callback. No `dangerouslySetInnerHTML`. |
| T-05-05 | Injection (XSS) | Story/Hero plain i18n text | mitigate | All other copy rendered as `{t(...)}` JSX text nodes; no raw HTML sink |
| T-05-06 | DoS | decorative blob/image assets | accept | Static, already-optimized assets in public/; served via next `Image` |
| T-05-SC | Tampering | npm/pip/cargo installs | mitigate | No package installs this plan (framer-motion/next-intl already present) |
</threat_model>
